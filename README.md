# 医療費控除 明細自動作成

スマホで撮影した領収書をOCR（文字認識）で読み取り、国税庁の「医療費集計フォーム」
（`iryouhi_form_v3.1.xlsx`）に自動で明細を追記していく、無料で使えるシンプルなWebアプリです。

**プログラミングの知識がなくても、この手順どおりに進めれば、あなた専用の医療費控除アプリを
スマホのホーム画面に置いて使えるようになります。**

> ⚠️ このアプリはビルド不要の素の HTML / CSS / JavaScript のみで作られています。`npm install` の
> ようなインストール作業は一切不要です。ブラウザで直接開くか、後述のGitHub Pagesで公開するだけで
> 動作します。

## 主な機能

- 📷 スマホのカメラで領収書を撮影 / 画像をまとめて選択してアップロード
- 🔍 Google Cloud Vision APIで領収書から金額・日付・医療機関名・患者名を自動抽出し、
  確認・修正してから登録（OCR結果は下書きなので必ず目視確認してください）
- 👪 家族の氏名・よく使う医療機関をあらかじめ登録しておくと、OCR結果が近い候補を自動選択
- 📊 登録するたびに `iryouhi_form_v3.1.xlsx` にリアルタイムで反映（画像・ロゴ・シート保護・
  入力規則などは一切崩さず、値だけを書き込みます）
- 📅 年度ごとにタブを分けて、複数年分を別々に管理・ダウンロード可能
- ⬆（任意）領収書画像はGoogle Driveの指定フォルダ（年度別サブフォルダ）に自動保存可能
- 🔁 `iryouhi_form_v3.1.xlsx` がバージョンアップした場合は、設定画面からファイルを差し替えるだけで
  以降の出力に反映されます

## 動作環境

- インターネットに接続できるWebブラウザ（Google Chrome、Safari、Microsoft Edgeなど最新のもの）が
  あれば、パソコン・スマートフォンのどちらでも動作します
- 特別なソフトのインストールは不要です
- 領収書のOCR読み取りには、後述の**Google Cloud Vision APIのAPIキー**が必要です（無料枠あり）

1. このページの右上にある **「Fork」** ボタンをクリックします
   （GitHubアカウントをまだお持ちでない方は、先にアカウント作成が必要です。作成手順は下の

   クリックします
3. 数秒待つと、あなた自身のGitHubアカウントにこのアプリの複製（コピー）が作成されます

### ステップ2: GitHub Pagesで公開する

Forkしたことで、あなたのアカウントに `iryouhi-kojo-meisai`（またはそれに似た名前）という
リポジトリができています。

1. そのリポジトリのページを開き、上部メニューの **「Settings」** タブをクリック
2. 左側メニューの **「Pages」** をクリック
3. 「Build and deployment」の **Source** で `Deploy from a branch` を選択
4. **Branch** を `main`、フォルダは `/ (root)` のままにして **Save** をクリック
5. 数十秒〜数分待つと、ページ上部に「Your site is live at
   `https://あなたのユーザー名.github.io/リポジトリ名/`」と表示されます

> 🔒 GitHub Pagesを無料で使うには、リポジトリが **Public（公開）** である必要があります。
> Fork直後はPublicになっているはずですが、もし「Upgrade or make this repository public to
> enable Pages」と表示された場合は、Settings → General → 一番下の「Danger Zone」→
> 「Change repository visibility」からPublicに変更してください。

### ステップ3: Google Cloud Vision APIを設定する

領収書のOCR読み取りには、あなた専用のAPIキーが必要です。手順は下の
「Google Cloudのセットアップ」を参照してください（無料枠の範囲内で使えます）。

設定が終わったら、発行されたURLをスマホのブラウザで開き、ブラウザのメニューから
「ホーム画面に追加」を選択すると、アプリのようにホーム画面から起動できるようになります。

- iPhone（Safari）: 共有ボタン（□に↑）→「ホーム画面に追加」

## データの保存について

このアプリはサーバーを持たない静的サイトです。明細データ・設定・テンプレートは
**ブラウザの IndexedDB**（Google Cloudの認証情報は localStorage）に保存されます。

- 同じブラウザ・同じ端末であれば、閉じても再度開いてもデータは消えません。
- **別の端末やブラウザとはデータが自動的に同期されません**（例：スマホで登録した明細はPCの
  ブラウザには表示されません）。
- ブラウザの履歴・サイトデータを消去すると、登録した明細データも失われます。定期的に
  「⬇ ダウンロード」でエクセルファイルを保存しておくことをおすすめします。

## Google Cloudのセットアップ（OCR利用に必須）

領収書のOCR（文字認識）にはGoogle Cloud Vision APIを使用します。以下の手順でAPIキーを発行し、
アプリの ⚙設定 画面に入力してください。これを行わないと領収書からの自動読み取りは動作しません
（テンプレートへの手入力・ダウンロード自体はAPIキーなしでも利用できます）。

> ⚠️ ここで発行するAPIキーは、**あなた専用のGoogle Cloudプロジェクト**で作成したものだけを
> 使ってください。他人が発行したAPIキーを使い回すと、その人に利用料金がかかってしまいます。

1. [Google Cloud Console](https://console.cloud.google.com/) で新しいプロジェクトを作成する
2. 「APIとサービス」→「ライブラリ」から以下を有効化する
   - **Cloud Vision API**
   - （Drive連携も使う場合）**Google Drive API**、**Google Picker API**
3. [お支払い](https://console.cloud.google.com/billing) で請求先アカウントを作成し
   （クレジットカード等の登録が必要）、対象プロジェクトにリンクする
   - Cloud Vision APIは無料枠内であっても請求先アカウントの紐付けが必須です
     （Googleの不正利用防止のための仕組みで、無料枠を超えなければ実際の請求は発生しません）
   - 未設定のままOCRを実行すると `This API method requires billing to be enabled` という
     エラーになります
4. 「APIとサービス」→「認証情報」→「認証情報を作成」→ **APIキー**
   - 作成後、「アプリケーションの制限」で「ウェブサイト」を選び、公開したGitHub PagesのURL
     （例: `https://<あなたのユーザー名>.github.io/*`）を追加しておくことを推奨します
   - 「APIの制限」で Cloud Vision API（Drive連携も使うなら Google Picker API も）を許可して
     おくとより安全です
5. アプリの ⚙設定 画面を開き、発行したAPIキーを入力して保存

Vision APIには毎月無料枠があり、家庭で使う程度の領収書枚数であれば通常は無料枠内に収まります
（詳細は [Cloud Vision の料金ページ](https://cloud.google.com/vision/pricing) を参照）。
領収書画像はOCRのためにGoogleのサーバーへ送信される点はご留意ください。

想定外の課金を避けたい場合は、
[予算とアラート](https://console.cloud.google.com/billing/budgets) から少額（例: 100円）の
予算アラートを設定しておくと、無料枠を超える利用があった場合にメールで通知を受け取れます
（アラートは通知のみで、自動的に利用を止めるものではない点に注意してください）。

APIキーはブラウザのlocalStorageに保存されるのみで、リポジトリには一切含まれません。

## Google Drive連携のセットアップ（任意）

領収書画像の自動アップロードを使わない場合はこの手順は不要です。

1. 上記の手順2で **Google Drive API** と **Google Picker API** も有効化しておく
2. 左メニュー「Google Auth Platform」（旧: OAuth同意画面）を開き、未設定なら「開始」から
   設定ウィザードを進める
   - アプリ情報: アプリ名、ユーザーサポートメール（自分のGoogleアカウント）
   - 対象: 個人利用なら「外部」を選択（審査不要の「テスト」ステータスのままでOK）
   - 連絡先情報: 自分のメールアドレス → 完了
   - ウィザード完了後、左メニュー「対象」を開き、「テストユーザー」に自分のGoogleアカウントを
     追加し、スコープに `drive.file`（本アプリが作成/選択したファイルのみアクセス）を追加する
3. 左メニュー「Google Auth Platform」→「クライアント」→「クライアントを作成」→
   **OAuthクライアントID**
   - アプリケーションの種類: ウェブアプリケーション
   - 「承認済みのJavaScript生成元」に公開したGitHub PagesのURL
     （例: `https://<あなたのユーザー名>.github.io`）を追加する
   - 「承認済みのリダイレクトURI」は不要（空欄のままでOK）。本アプリはポップアップ方式の
     トークンクライアントを使うため、リダイレクトURIは使用しません
   - 発行された「クライアントID」を控える
4. アプリの ⚙設定 画面を開き、クライアントIDを入力して保存
   （APIキーは上記のGoogle Cloudセットアップで入力済みのものを共用します）
5. 「保存先フォルダを選択」からGoogle Drive上の保存先フォルダを選ぶ
   - このピッカーには「新規フォルダを作成」機能がありません。新しいフォルダに保存したい場合は、
     先に [drive.google.com](https://drive.google.com) 側でフォルダを作成してから、ピッカーで
     選び直してください
6. 「登録時に領収書画像を自動でDriveへアップロードする」をオンにする

以降、明細を登録するたびに選択したフォルダの `<年度>` サブフォルダへ領収書画像がアップロード
されます。設定画面の「📂 Driveでフォルダを開く」から、保存先フォルダをブラウザで直接開いて
中身を確認できます。

アプリ内で明細を削除しても、Drive上にアップロード済みの領収書画像は削除されません
（明細データとDrive上のファイルは紐付けを持たない別々の保存先のため）。不要になった画像は
Driveのフォルダを直接開いて手動で削除してください。

### スマホで「Can't access your Google Account」と表示される場合

「保存先フォルダを選択」をタップした際に、Googleのログイン画面で
`Can't access your Google Account`（`We can't access this content right now. Try signing
into your Google account or allowing cookie access to proceed.`）と表示されることがあります。
これはブラウザのCookie制限によりGoogleのログインポップアップが正しく動作しないことが原因です。

**iPhone (Safari) の場合:**

1. 「設定」アプリ → 「Safari」→ 「プライバシーとセキュリティ」（iOSのバージョンによっては
   「詳細」の場合もあります）を開く
2. 「サイト越えトラッキングを防ぐ」をOFFにする
3. Safariを一度完全に終了し、アプリを開き直してから再度試す

この設定はSafari全体に影響するため、気になる場合はDrive連携を使う時だけ一時的にOFFにし、
終わったら再度ONに戻しても構いません。

**Androidの場合:**

同様の現象が起きる場合は、Chromeの「サードパーティ Cookie」のブロック設定が原因の可能性が
あります。Chromeアプリ → 右上のメニュー →「設定」→「プライバシーとセキュリティ」→
「サードパーティ Cookie」で、ブロックが有効になっていないか確認してください。

**共通の注意点:**

LINEやSNSアプリなどのリンクから開いた「アプリ内ブラウザ」では、Googleがセキュリティ上の理由で
ログインそのものを明示的にブロックしています。その場合は共有メニュー等から「Safariで開く」
「Chromeで開く」を選び、標準のブラウザで開き直してください。

なお、これはあくまでDrive自動アップロード（任意機能）に関する制限で、領収書のOCR読み取り →
エクセル明細作成・ダウンロードという中核機能には影響ありません。

## テンプレートのバージョンアップ対応

`iryouhi_form_v3.1.xlsx` が新しいバージョンに更新された場合:

1. アプリ下部の「テンプレートを差し替え」から新しいxlsxファイルを選択する
2. レイアウトが想定と異なる場合は警告が表示されます（それでも使用するか確認）
3. 以降のリアルタイム反映・ダウンロードは新しいテンプレートを使用します

テンプレートは年度ごとではなくアプリ全体で1つだけ保持する設定です。明細データ（氏名・金額・
日付など）はテンプレートとは切り離してIndexedDBに保存されているため、年の途中でテンプレートを
差し替えても、それ以前に入力した明細が消えたり変わったりすることはありません。

対応しているのは国税庁配布の「医療費集計フォーム」と同じレイアウト（データ入力範囲:
B9:J1003、列構成: 氏名/名称/区分4列/支払額/補填額/支払日）です。レイアウトが大きく変わった
新バージョンの場合は `js/xlsxPatch.js` 内の `COLS` / `DATA_START_ROW` の調整が必要です。

## ローカルでの動作確認（開発者向け）

`index.html` をブラウザで直接開くだけでは一部機能（OCR・Drive連携）が正しく動作しない場合が
あります。簡易サーバーを立てて確認してください。

```bash
# 例：Pythonがある場合
python3 -m http.server 8000
# その後 http://localhost:8000/ を開く
```

## ファイル構成

```
index.html               画面のHTML本体
css/style.css            スタイル（レスポンシブ対応）
js/db.js                 IndexedDBへの保存・読み込み（明細・設定・テンプレート）
js/ocr.js                Google Cloud Vision APIの呼び出しと、金額・日付・医療機関名・
                          患者名の抽出ロジック
js/xlsxPatch.js           xlsxテンプレートの該当セルのみを直接書き換える処理
js/drive.js               Google Drive連携（OAuth・フォルダ選択・アップロード）

iryouhi_form_v3.1.xlsx    国税庁配布の医療費集計フォーム（同梱デフォルトテンプレート）
```

## 注意事項

- OCRの認識精度は完璧ではありません。登録前に必ず内容を確認・修正してください
- 医療費控除の要件（対象となる医療費の範囲等）については国税庁の案内をご確認のうえ、最終的な
  内容は必ずご自身で確認してください
- 確定申告での提出は「医療費控除の明細書」のみで足りますが、**領収書の原本は確定申告期限から
  5年間、自宅等で保管する義務があります**（税務署から提示を求められる場合があるため）。
  本アプリのGoogle Drive保存機能はあくまで控え・バックアップであり、原本の保管に代わるもの
  ではありません。紙の領収書は処分せずに保管してください
